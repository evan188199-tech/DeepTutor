# MN4 x DeepTutor 全类型阅读最佳实践

## 核心分工

| 角色 | 职责 |
|------|------|
| **MN4** | 连续精读、批注、脑图、个人长期知识沉淀。阅读体验优于 DeepTutor，是正文阅读的主力。 |
| **DeepTutor KB** | 保存可更新原始材料，提供可追溯检索。动态内容的唯一事实来源。 |
| **DeepTutor Book/Chat** | 解释、关系图、时间线、测验、练习、版本差异分析、知识漂移检测。 |
| **官方网站/原书** | 最终事实来源，用于交叉验证。 |

## 章节循环法

**不推荐**：DeepTutor 完整粗读一遍 -> MN4 再完整精读一遍（重复且低效）。

**推荐**：按章节循环 --

1. DeepTutor 预处理/导航（背景知识、关键词解释、本章重点）
2. MN4 精读正文 + 批注
3. DeepTutor 集中答疑和测试（针对 MN4 中的疑问）
4. 精炼结果回填 MN4 笔记（经人工确认）

## 场景一：动态网页教程

适用：Hermes Agent 文档、API 参考等持续更新的内容。

### 爬虫同步
- 用自定义爬虫定期抓取，同步到 DeepTutor KB
- 每个页面保留元数据：`canonical_url`、`content_hash`、`fetched_at`、版本号、有效/删除状态
- 使用稳定路径替换页面，避免新旧版本同时被检索

### 更新链路
1. 抓取差异检测（对比 `content_hash`）
2. 更新 KB 中的原始文档
3. 生成新索引版本
4. 查询验证新内容正确
5. 切换到新版本
6. Book 漂移检测标记陈旧页面
7. 重编译受影响页面
8. 确认新基线

### 内容分流
- 易变的命令、API、配置示例：留在 DeepTutor，随时更新
- 稳定的原理、架构理解、个人实验结论：进入 MN4 长期沉淀

## 场景二：静态技术书 / 双语书籍

适用：经典教材、O'Reilly 技术书、论文集等不再变化的内容。

### 是否制作双语 EPUB
- 长期精读且语言构成障碍时：制作段落级双语 EPUB，导入 MN4 阅读
- 语言无障碍或只需要查词：直接用原版 EPUB/PDF

### 流程
1. MN4 读正文，做批注和脑图
2. 遇到推导、证明、反例：丢给 DeepTutor `deep_solve` 做详细解释
3. 每章结束：DeepTutor 生成章节测验和闪卡
4. 测验结果和关键理解回填 MN4（人工确认）

## 场景三：复杂小说

适用：《百年孤独》等人物关系复杂、时间线非线性的文学作品。

### DeepTutor 维护的结构化数据

- **家族谱/人物关系图**：每章只更新增量，每 3-5 章生成总图
- **双轨时间线**：故事内时间（叙事年份） vs 叙事时间（章节顺序）
- **人物状态卡**：当前位置、状态、关键事件
- **地点迁移图**：人物在不同地点间的移动
- **意象与母题变化卡**：追踪反复出现的符号及其演变

### 防剧透机制
- 检索 KB 时必须按当前阅读章节限制材料范围
- 仅靠“不要剧透”提示词不够可靠，需要硬性章节过滤器
- DeepTutor Book 的阅读进度隔离功能是实现基础

### 流程
1. 每章前：DeepTutor 生成前情提要（仅基于已读章节）
2. MN4 精读正文
3. 每章后：DeepTutor 更新增量结构化数据（人物/时间线/地点）
4. 每 3-5 章：生成总览图，导入 MN4 作为参考

## DeepTutor Book 能力参考

| 能力 | 用途 |
|------|------|
| 时间线 | 小说时间线、历史事件梳理 |
| 概念图 | 人物关系、技术概念关联 |
| 测验 | 章节理解检验 |
| 闪卡 | 关键事实记忆 |
| 交互块 | 动态演示 |
| 知识漂移检测 | KB 更新后标记陈旧页面 |
| Markdown 导出 | 精炼内容导出供 MN4 导入 |

### KB 漂移检测行为
- `refresh-fingerprints` / “Mark as seen” 只更新基线并清除陈旧标记
- 不会自动重新生成页面
- 必须先手动重编译受影响页面

---

## MN4 写回原则

- DeepTutor 产出的精炼内容默认需经人工确认后才写入 MN4
- 不自动覆盖已有批注和笔记
- 导入格式优先使用 Markdown，MN4 可直接解析

---

## 日常节奏 SOP

1. 打开 MN4，继续上次阅读位置
2. 阅读中遇到疑问：标记后切到 DeepTutor 答疑
3. 章节完成：DeepTutor 测验/总结 -> 回填 MN4
4. 动态教程：检查 KB 是否有更新，有则查看变更摘要
5. 周末回顾：MN4 脑图全局审视，DeepTutor 生成综合测验
